MDP PROJECT

About BrailleBridge

Making digital communication more accessible.

Smartphone-Integrated Text-to-Speech System for an E-Braille Bench

BrailleBridge is a student project prototype that converts typed English to Braille, experiments with recognizing photographed Braille, and speaks translated text aloud. The bench is currently a visual simulation. Physical ESP32 and solenoid integration is planned for a later phase.
